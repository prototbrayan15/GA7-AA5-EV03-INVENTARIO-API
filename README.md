# INVENTAR-IO API

API desarrollada para el proyecto INVENTAR-IO como parte de la evidencia GA7-220501096-AA5-EV03.

## Funcionalidades

- Registro de usuarios.
- Inicio de sesión.
- Consulta de productos.
- Registro de productos.
- Eliminación de productos.
- Actualización de estado de venta.

## Tecnologías utilizadas

- Java
- Spring Boot
- Maven
- Postman
